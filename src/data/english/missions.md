ZeroLore lets you play any kind of battle you have in mind: you can create your own missions, scenarios and campaigns using the rulebook as a base. Here in missions you'll find the base game mode to set up a game quickly.

# Game Setup

Before starting, players agree on:

- The **command posts / Headquarters** to place on the table and where — they are used to deploy units and are conquest objectives.
- The **number of turns** — recommended: **5**.
- Each player's **total army value**.
- The **game mode** — Skirmish or Grand Battle.
- The **missions** being played. Each mission defines its own objectives.

Each player then builds their army up to the agreed Value, bearing in mind that:

- It must include **exactly one Hero**, whose faction ability defines the army's style.
- For each unit they must choose one of its three **weapon sets** (Assault, Balanced or Ranged), which is kept for the whole game.
- They may buy **items** with Value and assign them to their units.

The game can be won in two ways: capturing the enemy HQ — an immediate victory — or by points. How are points earned?

1. **Capturing command posts** — each command post provides **5 pts per turn**, including the HQ.
2. **Completing missions** — each completed mission provides points. Each player brings **2 missions** to the battle.

Missions are drawn from the mission deck; each player always holds **2**. On the first turn, during the initiative phase, once chosen, each player may swap them once; after that, they can only be swapped in later **Initiative Phases**. Discarded cards return to the deck. When a mission is completed, it is announced to the players, checked, removed from the deck, and kept by the player who completed it.

**Note on tokens:** Mission tokens are placed 9" from a neutral command post; a randomly chosen player places it wherever they like. If a mission is completed, the token is placed again by a player from the opposing team to the one who placed it before, and so on. A unit that makes base contact with the token picks it up and the token is removed from the battlefield; if it dies while carrying it, the token stays where the unit was. A player without a mission to carry the token cannot pick it up.
